## Validation and limitations

- The actual LinkedIn screenshot shows the source page. It does not prove the recording captured a saved import. The separate ten-person parser check must be described separately.
- A localhost preview cannot read a neighboring LinkedIn tab through Chrome extension APIs or run Chrome Google OAuth. The installed extension is required for those actions.
- The video shows Google connection controls, not an OAuth consent flow. A connected label, if visible, is only the app’s displayed status; it does not prove Gmail delivery, Calendar invitations, or Meet provisioning.
- Demo booking creates no Google event and no real Meet link. The live connector requests a Meet link; availability depends on account policy and provisioning.
- Booking uses a time selected by the user after agreement. Scheduling is not fully autonomous.
- LinkedIn import reads the open results page. It does not crawl the whole company or read private profile information. The user sends LinkedIn and X messages manually.
- Demo replies and the accelerated follow-up clock are simulations, not evidence of live inbox polling or a multi-day follow-up run. All real sends still require approval.
- No real outreach or Calendar creation was performed to produce this walkthrough. Keep keys, private inboxes, developer consoles, and OAuth tokens out of the video.
